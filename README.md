# SUTO Fashion — Android app

A Flutter app that opens the SUTO Fashion online store
(https://sutofashionecom.netlify.app) as a full-screen Android app. GitHub Actions builds
the APK and publishes it as a GitHub Release. The website's "Download App" button points at:

```
https://github.com/iamabdurrahimkhan/suto-fashion-app/releases/latest/download/suto-fashion.apk
```

That link always serves the newest release, so the website never needs changing after an update.

## What the app does

- Shows the store full-screen with a brand-colour status bar, a logo splash and a thin loading bar.
- Keeps store pages inside the app. WhatsApp orders, phone, email, Instagram and Facebook links open in their own apps.
- Android back button closes the open cart, menu, product page or image viewer first, then goes back a page, and needs two presses to exit.
- Shows a "No internet" screen with a **Try again** button.
- Opens the site with `?app=1`, so the site hides its own "Download the app" banner and buttons inside the app.

## Publish a build

1. Create a **public** repo named `suto-fashion-app` and upload everything in this folder.
   Keep the `.github` folder; it is hidden on some computers.
2. *(Recommended)* Add the three signing secrets from `signing-secrets.txt`:
   **Settings → Secrets and variables → Actions → New repository secret**:
   `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`.
   Without them the build still works, but it is debug-signed and a new APK will not install over an old one.
3. **Actions → Build APK → Run workflow.** The first build takes about 8–10 minutes.
4. When it finishes, **Releases** shows `suto-fashion.apk`, and the website's download button works.

Each later run publishes `v1.0.<run number>`, which updates the installed app.
You can also push a tag such as `v1.2.0` to publish that version.

## Reuse for another client

Edit the three constants at the top of `lib/main.dart` (`kStoreUrl`, `kBrand`, `kAccent`).
Then replace `assets/icon.png` and `assets/icon_fg.png` (1024×1024), and the app name
`android:label` in `android/app/src/main/AndroidManifest.xml`. For a separate app on the
same phone, also change `--org`/`--project-name` in `.github/workflows/build-apk.yml`.

## Files

| Path | Purpose |
|---|---|
| `lib/main.dart` | The whole app |
| `android/app/src/main/AndroidManifest.xml` | App name, internet permission, external-link handling |
| `android/app/src/main/res/` | Brand-colour launch screen (Android 5–15) |
| `assets/icon.png`, `assets/icon_fg.png` | Launcher icon + adaptive-icon foreground |
| `.github/workflows/build-apk.yml` | Build, sign and release |

The rest of the `android/` folder is generated by `flutter create` during the build.
